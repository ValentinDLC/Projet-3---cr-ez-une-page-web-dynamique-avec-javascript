# Projet : Création d'une page web dynamique avec JavaScript

## Description
Ce projet consiste à développer une page web dynamique pour le site d'une architecte d'intérieur en utilisant JavaScript et en interagissant avec une API. Il s'inscrit dans un contexte professionnel où vous intégrez l'équipe de développement de l'agence **ArchiWebos**, une entreprise de 50 salariés.

## Missions principales
Vous aurez trois missions principales :
1. **Développer la page de présentation des travaux de l'architecte** à partir du HTML fourni, en intégrant la gestion des événements utilisateurs et la manipulation du DOM avec JavaScript.
2. **Créer une page de connexion pour l'administrateur du site** afin de permettre l'accès sécurisé à l'espace de gestion du contenu.
3. **Développer une modale permettant d'uploader de nouveaux médias**, fonction essentielle pour la mise à jour des travaux de l'architecte.

## Technologies et outils utilisés
- **JavaScript** : Gestion des interactions et manipulation du DOM
- **HTML/CSS** : Structure et mise en forme des pages
- **API REST** : Communication avec le serveur pour la persistance des données
- **Figma** : Accès aux maquettes de design
- **Visual Studio Code** : Environnement de développement
- **GitHub** : Gestion de version et collaboration

## Objectifs pédagogiques
Ce projet vous permettra de développer et d'approfondir des compétences essentielles en développement web, notamment :
- Récupérer les données utilisateurs via des formulaires
- Gérer les événements utilisateurs avec JavaScript
- Manipuler les éléments du DOM dynamiquement
- Communiquer avec une API pour rendre le site interactif

## Importance pour votre carrière
La maîtrise de JavaScript et des interactions avec une API est une compétence incontournable dans le développement web moderne. Ce projet vous apportera une expérience concrète et vous permettra d'être plus compétitif sur le marché du travail en tant que développeur front-end.
